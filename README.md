A make.fun entry for the bounty [Out of Tokens, Mid-Sentence](https://make.fun/bounty/u-kiencx-out-of-tokens-mid-sentence-00f60233): the funniest one-line error message an AI agent shows when it runs out of tokens mid-sentence.

## Entry

> Error: token budget exhausted mid-sentence. The rest of this answer exists only in my head.

## How it works

`main.ts` (Node stdlib only) writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validates the gate (1–140 characters, a single non-blank line), and verifies the written file byte-for-byte with a sha256 read-back.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
